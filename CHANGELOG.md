# Changelog

## [1.2-alt1] - 2025-11-27

### Added

- new parameter `-f` or `--force` or `--yes`
- new parameter `-k` or `--keep-package`
- new parameter `-q` or `--quiet`
- a request to the user to confirm the update
- a screenshot of the c10f1 update

### Fixed

- changed some defaults and cmdline parameters
- changed the default behavior of the `--username=...`
- updated and improved the package documentation and help

### Removed

- parameter `--autoclean`
- parameters `-v` and `--verbose`
- os-upgrade autorun from the spec's %post for c10f1

[1.2-alt1]: https://github.com/klark973/os-upgrade/releases/tag/1.2-alt1

## [1.1-alt1] - 2025-11-22
