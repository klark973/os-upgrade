# Инструмент обновления ОС Альт

Пакет `os-upgrade` предназначен для глобального обновления дистрибутива
ОС Альт, т.е. перехода с одного бранча (исходного) на следующий (целевой).
Обновление выполняется полностью автоматически без участия пользователя,
при этом учитываются все нюансы миграции на следующий бранч.

## Системные требования

Окончательные системные требования зависят от поддерживаемого целевого
обновления из состава программы, таковые доступны в соответствующих
подкаталогах. Например, см. эталонную реализацию обновления Альт СП
релиз 10 ([c10f1](/doc/README-c10f1-ru.md)).

В любом случае подразумевается продуктовая ОС Альт. Нужно заблаговременно
позаботиться о свободном месте на диске, его должно быть не менее 25% до
запуска программы. По умолчанию до начала обновления проверяется доступность
сетевого подключения. Для замкнутого контура с собственным зеркалом данную
проверку можно отключить или указать собственный сервер для такой проверки.

## Возможности os-upgrade

* автоматическое определение поддерживаемого целевого обновления;
* поддержка официальных публичных Интернет репозиториев ОС Альт;
* поддержка зеркал на подключаемом носителе или на локальном диске;
* поддержка зеркал в локальной сети, в т.ч., для замкнутых контуров;
* поддержка защиты IMA/EVM: она отключается автоматически перед обновлением,
  а после обновления может быть включена обратно, даже в том случае, если
  ранее не была включена, это зависит от параметров запуска программы;
* поддержка фонового режима обновления с наименьшим числом перезагрузок:
  только для серверов без установленного графического рабочего стола;
* поддержка более безопасного обновления в изолированном таргете systemd;
* расширенная диагностика выполняемого обновления с параметром `--verbose`;
* автоматическое определение непривилегированного пользователя, вошедшего
  в систему, которому должен быть доступен процесс мониторинга обновления;
* возможность подключения дополнительных источников APT (sources.list)
  в процессе обновления: выполняется после переключения на целевой бранч;
* автоматический (отключаемый) запуск обновления при установке пакета:
  результат этого запуска в случае фатальных ошибок будет доступен во
  временном журнале `/var/log/os-upgrade-err.log`;
* по ходу обновления ведётся регулярный журнал `/var/log/os-upgrade.log`,
  он выводится на TTY@TTY_NUMBER@ (`Alt-F@TTY_NUMBER@`) и к нему можно
  подключиться с любого терминала интерактивно через `os-upgrade --show`;
* поддерживается три режима цветности журнала и вывода в терминал: обычный,
  цветной и автоопределение (по умолчанию);
* программа может не оставить за собой никаких следов после того, как
  выполнит обновление с опцией `--autoclean`.

## Установка и запуск программы

Для выполнения обновления сделайте резервные копии ценных данных и настроек
системы, временно отключите службы, которые не должны запускаться во время
обновления, в графической среде закройте все не нужные приложения, после
чего выполните в терминале:

```bash
$ su-
# apt-repo test <номер таска>
```

где `<номер таска>` соответствует поддерживаемому целевому обновлению. При
этом пакет os-upgrade будет доставлен из «временного кармана», установлен
и сразу начнётся процесс обновления с параметрами по умолчанию. Если нужно
задать какие-то особые параметры, то разделить установку пакета и запуск
программы можно установкой переменной окружения `DURING_INSTALL`, например:

```bash
$ su-
# export DURING_INSTALL=1
# apt-repo test <номер таска>
# os-upgrade --help
```

После установки пакета доступна подсказка на русском и английском языке,
в зависимости от текущей локали. Для систем, защищённых механизмом IMA/EVM,
запустить `os-upgrade` напрямую не получится, для них предусмотрен второй
вариант запуска программы: `/bin/bash /usr/bin/os-upgrade --help`. Пока
пакет не удалён из системы, можно мониторить происходящее обновление, в
том числе, со стороны обычного пользователя, которому это было разрешено:
`os-upgrade -s`. После успешного окончания обновления с опцией `--autoclean`
в системе останется только журнал обновления, который можно посмотреть так:

```bash
$ less -R /var/log/os-upgrade.log
```

Чтобы запретить автоопределение обычного пользователя, чтобы сделать для
него недоступными журнал обновления и процесс мониторинга, используйте при
запуске программы ключ `--username=-`. Если программа ставится в замкнутом
контуре без доступа во внешнюю сеть, вместо `apt-repo test <номер таска>`
используйте такие команды:

```bash
$ su-
# export DURING_INSTALL=1
# apt-get install /путь/к/os-upgrade-*.noarch.rpm
# nohup os-upgrade --autoclean --background --mirror=<зеркало> \
    --color=always --verbose --ping-server=- >/var/log/os-upgrade-err.log 2>&1 &
```

предварительно скачав пакет и разместив на локальном диске, где `<зеркало>` –
это начальный путь с исходным и целевым репозиториями в локальной файловой
системе (например, /ALT или file:/ALT), либо обычный FTP/HTTP URL локального
сервера с зеркалом (например, http://example.org/ALT). В качестве `<ping-server>`
можно также указать реальный IP-адрес в локальной сети. Если этого не сделать,
то уже при установке пакета обновление начинается автоматически с отправкой
пингов на `ya.ru` и с использованием официального зеркала.

В самом начале обновления программа переключит активный терминал на TTY@TTY_NUMBER@,
при этом она сама запустит одноимённый сервис, а ближе к окончанию работы
переключит активный терминал обратно на TTY1. Зразу после запуска программы
можно успеть выйти из графического сеанса, чтобы ничего не мешало процессу
обновления, и чтобы мониторить происходящее на выделенном для этого терминале.

Если что-то пошло не так на самом раннем этапе, смотрите временный журнал
(`/var/log/os-upgrade-err.log`). После устранения проблем утилиту можно
попробовать запустить заново, но сначала придётся удалить ранее созданные
ей файлы и каталоги:

```bash
$ su-
# rm -f /etc/systemd/system/os-upgrade*
# rm -rf /var/lib/os-upgade /usr/local/libexec/os-upgrade
# os-upgrade ... (нужные вам параметры)
```

После частичного выполненного обновления это уже, скорее всего, не поможет.
Обратите внимание: никакие другие файлы пакета удалять вручную не следует!

## Источники APT и сторонне ПО

В начале обновления все сторонние источники APT отключаются, подключается
только официальное зеркало исходного бранча. То же самое происходит и при
обновлении индексов из целевого репозитория, но в этом случае можно заранее
подготовить файл со списком дополнительных источников и указать к нему путь.
Если этого не сделать, то уже установленное в системе стороннее ПО не
обновится, что может повлечь конфликт зависимостей. Как вариант, стороннее
ПО может оказаться несовместимо с библиотеками из целевого бранча. Так что,
если требуется учитывать стороннее ПО, используйте ключ `--apt=` и запускайте
обновление вручную через `DURING_INSTALL=1`.

## Ограничения и предостережения

Обратите внимание: программа не предназначена для обновления систем с
поломанной пакетной базой, неразрешёнными циклическими зависимостями сервисов
systemd или проблемами переключения между графическими режимами (modesetting).
Программа требует наличия определённых предустановленных пакетов, характерных
для официально выпущенных продуктов ОС Альт. Вы не сможете обновлять с её
помощью стартеркиты или регулярки на основе SysV init, равно как и другие
не продуктовые сборки.

В случае неисправимых проблем в процессе обновления, например, при временной
потере связи с публичным зеркалом, система может оказаться в недообновлённом
или в полностью неисправном состоянии. Поэтому заблаговременно позаботьтесь
о качественном Интернет соединении, свободном месте на диске, бесперебойном
питании от электросети и резервной копии своей системы.

Хотя программа стремится минимизировать ваши риски, успех обновления
не гарантирован. Всегда выполняйте обновление с ключом `--verbose`. При
возникновении проблем, регулярный журнал может пригодиться для восстановления
работоспособности системы и разбора инцидента, в том числе, вашей технической
поддержке, но только, если при обновлении использовался ключ `--verbose`.

Сообщайте об ошибках на https://bugzilla.altlinux.org/


Удачного обновления! ;-)
